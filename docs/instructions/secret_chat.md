# Как создать секретный чат
Секретные чаты обеспечивают сквозное шифрование, самоуничтожение сообщений и запрет на пересылку.

!!! warning "Внимание"
    Инструкция разработана с помощью ИИ и может содержать неточности.

## Инструкция

1. **Откройте Telegram**
2. **Нажмите на иконку создания нового сообщения** (карандаш или значок редактирования)
3. **Выберите "Новый секретный чат"**
4. **Выберите контакт** из списка
   - *Примечание: можно выбрать только контакт из вашей адресной книги*
5. **Дождитесь установки соединения**
   - Иконка замочка 🔒 в верхней части экрана подтвердит активацию шифрования

## Особенности

- Работает только на устройстве, где создан
- Сообщения нельзя переслать или сохранить
- Доступен таймер самоуничтожения (настройка в меню чата)
- История чатов не хранится в облаке
